## 📖 Overview

Print Management System is a cloud-native web application developed for managing print orders through an integrated customer and administrator platform.

The system is designed to simplify order processing, pricing management, file uploads, authentication, and production workflow.

---

## ✨ Key Features

- Customer Authentication
- Admin Dashboard
- Online Print Orders
- Dynamic Pricing
- File Upload
- Invoice Management
- User Management
- JWT Authentication
- Secure Password Hashing
- Cloudflare D1 Database
- REST API
- Responsive Design
